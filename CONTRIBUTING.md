# 参与项目 / Contributing

肥鱼笔记还处于早期阶段，目标是小而美。欢迎通过 [Issues](https://github.com/Yongzhaooo/FeiyuNote/issues) 报告问题、提出功能建议或讨论使用体验；**暂不接受 Pull Request**。

报告问题时，请提供 Android 版本、应用版本、复现步骤，以及不含个人信息的截图。不要提交 API Key、私人笔记或个人照片。

Feiyu Notes is at an early stage. We aim to keep it small and focused. Bug reports, feature suggestions, and feedback are welcome in [Issues](https://github.com/Yongzhaooo/FeiyuNote/issues). **We are not accepting pull requests for now.**

Please include your Android version, app version, reproduction steps, and screenshots without personal information. Never submit API keys, private notes, or personal photos.
